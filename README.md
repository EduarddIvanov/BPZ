# Шифр DES (симетричне блокове шифрування)

Практична робота №5 з дисципліни «Безпека програмного забезпечення».
Криптосистема симетричного блокового шифрування з графічним інтерфейсом.

## Можливості

- шифрування та розшифрування за алгоритмами DES, TripleDES і AES
- динамічний вибір алгоритму та режиму зчеплення (ECB, CBC, CFB, OFB)
- генерація випадкового ключа й вектора ініціалізації
- подання ключа, IV та шифрограми у форматі base64
- робота з файлами: створення, відкриття, збереження

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Структура

- `symmetric_cipher.py` — логіка шифрування (DES / TripleDES / AES, режими)
- `main.py` — графічний інтерфейс (PySide6)
- `test_symmetric_cipher.py` — тести
