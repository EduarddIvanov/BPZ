# Шифр Тритеміуса

Практична робота №2 з дисципліни «Безпека програмного забезпечення».
Криптосистема симетричного шифрування на основі шифру Тритеміуса з графічним інтерфейсом.

## Можливості

- шифрування та розшифрування тексту українською і англійською мовами
- три види ключа: лінійне рівняння (A, B), нелінійне рівняння (A, B, C) та гасло
- робота з файлами: створення, відкриття, збереження, перегляд перед друком
- атака на шифр за відомою парою «відкритий - зашифрований текст»

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Структура

- `trithemius.py` — класи шифрування, ключів та валідації
- `trithemius_attack.py` — атака за відомим відкритим текстом
- `main.py` — графічний інтерфейс (PySide6)
- `test_trithemius.py` — тести
