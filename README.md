# Електронний цифровий підпис на основі RSA

Практична робота №8 з дисципліни «Безпека програмного забезпечення».
Система формування та перевірки ЕЦП на основі алгоритму RSA з графічним інтерфейсом.

## Можливості

- генерація пари «відкритий - закритий» ключі (1024 / 2048 / 3072 / 4096 біт)
- окремий діалог формування ключів із виведенням їх у форматі PEM
- підписування довільного повідомлення закритим ключем
- перевірка підпису відкритим ключем з виведенням вердикту
- вибір алгоритму гешування (SHA-1 / SHA-256 / SHA-512)
- виведення геша повідомлення у шістнадцятковому вигляді
- подання підпису у форматі base64
- робота з файлами: створення, відкриття, збереження

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Структура

- `rsa_signature.py` — логіка ЕЦП: геш (SHA) + підпис RSA (pkcs1_15)
- `main.py` — графічний інтерфейс (PySide6)
- `test_rsa_signature.py` — тести

## Принцип роботи

Підпис формується у два кроки: з повідомлення обчислюється геш (SHA), який потім
шифрується закритим ключем відправника - це і є цифровий підпис. Для перевірки
отримувач обчислює геш того самого повідомлення і через відкритий ключ підтверджує,
що підпис відповідає цьому гешу. Якщо повідомлення або підпис змінено, перевірка не
проходить.
