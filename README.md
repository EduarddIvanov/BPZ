# Шифр Цезаря

Практична робота №1 з дисципліни «Безпека програмного забезпечення».
Криптосистема симетричного шифрування на основі шифру Цезаря з графічним інтерфейсом.

## Можливості

- шифрування та розшифрування тексту українською і англійською мовами
- робота з файлами: створення, відкриття, збереження, перегляд перед друком
- підбір ключа методом грубої сили (перебір)
- шифрування файлів довільного формату

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Структура

- `caesar.py` — класи шифрування та валідації
- `bruteforce.py` — атака перебором ключів
- `main.py` — графічний інтерфейс (PySide6)
- `test_caesar.py` — тести
