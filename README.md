# Книжковий шифр

Практична робота №3 з дисципліни «Безпека програмного забезпечення».
Криптосистема на основі книжкового (віршованого) шифру з графічним інтерфейсом.

## Можливості

- віршований шифр: символ кодується координатами (рядок/стовпець) у таблиці-вірші
- налаштування розміру таблиці ключа та перегляд самої таблиці
- випадковий вибір координат, коли символ трапляється у вірші кілька разів
- пословний книжковий шифр: слово замінюється номером слова з тексту-ключа
- робота з файлами: створення, відкриття, збереження

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Структура

- `book_cipher.py` — віршований шифр і клас ключа-вірша
- `word_book_cipher.py` — пословний книжковий шифр (додаткове завдання)
- `main.py` — графічний інтерфейс (PySide6)
- `test_book_cipher.py` — тести
