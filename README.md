# Шифр RSA (асиметричне шифрування)

Практична робота №7 з дисципліни «Безпека програмного забезпечення».
Криптосистема з відкритим ключем на основі алгоритму RSA з графічним інтерфейсом.

## Можливості

- генерація пари «відкритий - закритий» ключі (1024 / 2048 / 3072 / 4096 біт)
- окремий діалог формування ключів із виведенням їх у форматі PEM
- шифрування повідомлення відкритим ключем (RSA-OAEP)
- розшифрування закритим ключем
- подання шифрограми у форматі base64
- робота з файлами: створення, відкриття, збереження
- навчальний RSA на малих простих числах (`TextbookRSA`) для перевірки на чисельному прикладі

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Структура

- `rsa_cipher.py` — логіка RSA: повноцінне шифрування через pycryptodome і навчальний RSA на малих числах
- `main.py` — графічний інтерфейс (PySide6)
- `test_rsa_cipher.py` — тести

## Чисельний приклад

Класичний приклад з Вікіпедії (p = 61, q = 53, e = 17): n = 3233, φ(n) = 3120,
λ(n) = 780, закритий показник d = 413 (обчислюється за функцією Кармайкла λ).
Для m = 65 шифрограма c = 65^17 mod 3233 = 2790, назад 2790^413 mod 3233 = 65.
Реалізовано у класі `TextbookRSA`, перевіряється у тестах.
